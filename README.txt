JESUS EMBASSY — FOR ALL NATIONS
Website starter files

FILES
- index.html: website content and sections
- styles.css: responsive black-and-gold design
- script.js: navigation, contact settings, and prayer request flow
- assets/je-mark.svg: simple gold JE seed-and-growth emblem
- assets/favicon.svg: browser tab icon

PREVIEW ON YOUR COMPUTER
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html. It opens in your browser.
   Internet is only needed for the optional Google Fonts; the website layout itself is local.

BEFORE PUBLISHING
1. Open script.js in Notepad or another text editor.
2. Your primary WhatsApp (+265993250016), secondary WhatsApp (+265885914196), and email (yolamugerald2@gmail.com) are already configured in script.js. You can change them there if needed.
4. Save the file and refresh index.html to test it.
5. Replace the sample event details and gallery placeholders in index.html with confirmed details and your own media.
6. The donation section is intentionally informational only. Add official, verified donation details or a trusted payment provider before accepting donations. Do not publish private banking details.

PUBLISH FREE WITH GITHUB PAGES
1. Create/sign in to a GitHub account at https://github.com/
2. Create a new public repository, e.g. jesus-embassy-website.
3. Upload index.html, styles.css, script.js, and the entire assets folder (keep the same folder structure).
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for the deployment and open the Pages URL shown there.
   GitHub's menus can change, so follow the current on-screen instructions.

OTHER HOSTING OPTIONS
You can also publish the same files with Netlify or another static website host. Upload the extracted project folder, keeping the assets folder included.

IMPORTANT
- The prayer request form opens WhatsApp only after you add the ministry's number. It does not store requests on a server.
- The live-services section is a placeholder for a future YouTube/Facebook/other live link.
- This starter site does not yet have a private admin dashboard or online payment processing.
